# CLOUD-03.3C — Backend de laboratorio cerrado
Migración de laboratorio (snapshot; no reaplicar si existe) y Edge Function candidata. Bucket separado privado, límite 8 MiB + tag, ocho intenciones por archivo, gate false. RLS permite rutas exactas sólo con intención visible y gate activo. RPC SECURITY INVOKER exclusivamente service_role, vuelve a comprobar membresía/huella bajo lock y CAS; no permiso de cliente para escribir intención. La Edge verifica usuario por getUser y bytes por hash; secreto service_role sólo runtime. CORS local restringido a localhost:8000 (no sustituye auth). No habilitar gate ni desplegar versión pública hasta pruebas de grants, revisión de runtime y pruebas negativas. No integrar recuerdos reales. La lectura de cabeceras publicadas y UI de laboratorio aún pendientes. Sin limpieza automática, no borrar/reemplazar objetos de lab mientras se confirma. El servidor no prueba posesión de clave ni distingue datos reales de ficticios. Copia del núcleo #27 incluida para despliegue autocontenido; mantener sincronizada.
