# CLOUD-03.4A — Codec cifrado v3 (offline)
Fuente: app/archive-v3.js y contrato de guardado de app/index.html. Formato nuevo archivito-sync-record-v3, deliberadamente incompatible con backend/cola de fixture. No se incorpora a dist ni interfaz, no escribe IndexedDB ni Supabase. El ID local (incluido legado no UUID), metadatos, orden e ID de hojas, pies, recortes, originales/derivados, MIME y bytes se mantienen dentro del manifiesto/activos cifrados. Miniaturas y alias de primera hoja se reconstruyen; no se sincroniza miniatura original. SHA-256 autenticado por manifiesto y AES-GCM vinculado a archivo/objeto/revisión/huella. La identidad remota UUID se asignará en un mapa persistente separado, no se deriva del ID local ni se cambia éste. Cada operación conserva el mismo paquete cifrado en futuros reintentos; no recifrar.
Límites: 25 hojas, 100 activos, JPEG/PNG/WebP/GIF, 35 MiB por activo, 128 MiB agregado y 256 KiB manifiesto. Límite agregado nuevo por memoria, no cuota de servidor. La implementación materializa paquetes en memoria; no apta aún para móviles con cartas grandes. Rechaza campos requeridos faltantes, recortes no JSON, hojas duplicadas, inconsistencias y límites sin truncar. Sólo registros schemaVersion=3 completos; v1/v2 o importaciones anómalas requieren normalización explícita posterior; no corregir silenciosamente. Campos de extensiones fuera de contrato no se sincronizan. Validación de imagen y generación de miniatura se inyectan; pruebas unitarias con blobs sintéticos no equivalen a decodificar imágenes reales. No se admite borrado remoto.
Próximos cortes: adaptar transporte/cola/backend con contrato distinto, límites y staging streaming/TUS, mapa de identidad persistente, validación real de imágenes, revisiones bidireccionales y reconciliación conservadora (no sobrescribir borradores). Prueba tercero real, custodia/rotación y respaldo antes de datos personales. Gate fixture cerrado tras prueba #29; ninguna escritura real habilitada.
