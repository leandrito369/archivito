# CLOUD-03.4D4A — Adaptador remoto v3
Cliente explícito disabled por defecto, scope usuario/archivo/huella y guardas de acceso antes/después de I/O. Bearer de getSession sólo como credencial; servidor autentica getUser y RPC valida membresía. POST begin/block/commit, comprobantes exactos, skip bloques ya atestados, descarga privada de revisiones confirmadas por RLS y reconstrucción verificada. Worker one-shot actualiza outbox sólo por recibo válido del adaptador; error conserva bytes, conflicto no reintenta automáticamente. No UI ni integración de biblioteca real en dist. No retry automático ni timer; lease existente puede vencer durante transferencia larga (idempotencia evita duplicado, falta renovación). Lectura no certifica sesión revocada antes de que expire JWT. El cliente debe descifrar con codec v3 antes de materializar.
