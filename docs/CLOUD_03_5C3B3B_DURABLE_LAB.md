# CLOUD-03.5C3B3B — Cola, caché y UI de certificación
Base #49 ambas CI verde. IndexedDB archivito-incremental-cert-v1, stores jobs/heads/cache, scope usuario/archivo/clave/memoria, wire y bloques cifrados antes de red, CAS base local, claim token lease 30s renovado cada 10s, finish atómico head+delete de job sólo recibo exacto, error/conflict preservados, retry exacto tras cierre/reload. Sin persistir clave ni record descifrado. Cache ciphertext hash verificado en cada lectura, límite global 64 MiB por store lógico (jobs y cache separados), máximo 8 jobs, si cache llena no agrega; nunca descarta jobs. No eviction automática ni resolución de conflicto. Lease browser usa reloj local, no garantiza fencing servidor ni quiescencia; idempotencia backend protege replay. 
UI sólo tras unlock; tres memorias fijas, tamaños PNG aproximados (280/1500/1900px ruido y reverso 160px); metadata-only, reemplazo reverso, lectura, retry, status, abort; métricas locales, cache hits y bytes nuevos/descargados. No biblioteca personal ni entrada de archivos. Cancelar aborta transporte, no revierte commit servidor. La recuperación tras cierre requiere nueva sesión/unlock y retry. Cold read vs warm, muestra creada no cacheada hasta lectura. Aprobación de storage real y benchmark aún pendiente. Gate hard closed; UI no habilita nada. Antes de apertura: scope fijo SQL y expiración, límites, fencing, prueba negativa, CI verde; sólo fixture permitido. Prueba Chromium real de persistencia, scope, lease, receipt y cache; no red real.
